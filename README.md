# Ajmol Hossain — Resume

A clean, responsive, print-friendly resume built with semantic HTML & CSS.

🔗 **Live:** [View Resume](https://ajmol.github.io/resume/) *(update with your actual GitHub Pages URL)*

## Tech Stack

- Semantic HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Google Fonts (DM Serif Display + Inter)
- No frameworks — pure HTML/CSS

## Features

- ✅ Responsive — looks great on mobile, tablet, and desktop
- ✅ Print-friendly — `Ctrl+P` to get a clean PDF
- ✅ Accessible — semantic markup, proper heading hierarchy
- ✅ Fast — no JavaScript, no frameworks, zero dependencies

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch** → `main` → `/ (root)`
4. Your resume is live at `https://<username>.github.io/<repo-name>/`
